## 这个仓库最值钱的部分：语料实证

市面上所有"孙哥体教程"都是读后感。这个仓库里的规则全部来自对原帖的**程序化验尸**：

- 正文 **413 句**，中位句长 **12 字**——不是"短句"这种模糊印象，是 12 字
- **"我说好"不多不少出现 7 次**，次次单独成段
- **161 处数字表达**，平均每 44 字一个数字——"报销单语感"就是这么来的
- 发长文前 1 小时他还在发直播预告，发完 1 小时继续喊单。**527 万阅读，是他同日常规推文的 6 倍**

详见 [corpus/量化文体分析.md](corpus/量化文体分析.md)、[corpus/时间线实测记录.md](corpus/时间线实测记录.md)（用登录态实抓 x.com/sunyuchentron 的原始数据）。

## 这是什么

一个 Claude Code / Kimi Code 的写作风格 skill（`SKILL.md`）。
装好之后，你的 AI 就学会了 2026 年开年第一篇十万加的写法——

**用会计的笔法写爱情，用爱情的笔法写账单。**

当年新概念作文大赛教你"我手写我心"。
孙哥体教你：**我心一个字不写，你自己从账单里看。**

普通作者写失恋：我很难过。
孙哥体写失恋：

```
我把手放在胸口，数了一下。
心跳很稳。
我又数了一遍，还是很稳。
```

## 三条铁律（SKILL.md 里有完整的八条自检清单）

1. **一句一段。** 中位 12 字，句号是唯一的奢侈品。
2. **数字精确到个位。** 二十六个人。四十几页。快一个小时。
3. **"我说好"是节拍器。** 全文所有的"好"，都是为了最后一次"让我想想"。
