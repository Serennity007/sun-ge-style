# 孙哥体.skill

我看到孙宇晨的《我的女友景甜》这篇帖子，抛开内容、事实、动机，我觉得文风写的是真的好——所以我把这 7000 字用程序验了尸，把每一根骨头都量了一遍，做成了这个写作 skill。

基于对原文的**程序化验尸**（413 句逐句测量 + 作者 X 时间线登录态实抓），
提炼 **7 条硬规则、3 组对照公式、8 条自检清单**，
经 **4 轮"生成→对抗评审→修正"测试**验证可复现。

## 效果示例

**问：用孙哥体，写我被裁员的事。**

> 孙哥体 ❯ 一把工位椅的价格，四百五十块。
> 　　　　一轮裁员的赔偿，八百万。
>
> 　　　　裁员那天 HR 找我谈。会议室提前订好了，三十分钟，后面还有人。
> 　　　　HR 说，N+1。我说好。
> 　　　　HR 说，今天签有额外两个月。我说好。
> 　　　　HR 愣了一下，说你不问问为什么是你吗。
>
> 　　　　我没有问。
>
> 　　　　她桌上有一份名单，打印的，钉起来的。
> 　　　　我签字的时候看见第二页还有名字。她说，今天谈八个。
>
> 　　　　……
>
> 　　　　那罐可乐我后来还是喝了。2019年的可乐，喝起来跟自来水一个味道。
> 　　　　生产日期印在罐底，我找了很久。

**问：写我妈。没钱的故事行不行？**

> 孙哥体 ❯ 一张存折的重量，九克。
> 　　　　我大学四年学费的重量，三万二。
>
> 　　　　……
>
> 　　　　销户要签字。我签完，柜员把存折收回去，剪了角。
> 　　　　我说这个能给我吗。
> 　　　　她说，剪了角的不能给。规定。
>
> 　　　　我说好。

**问：写我们公司日活破百万的喜报？**

> 孙哥体 ❯ 写不了。这个题材里没有"失去"。
> 　　　　孙哥体的引擎是失去——全文所有的铺陈，
> 　　　　都是为了最后那件没发生的事。
> 　　　　你要是非要写，改成："日活破百万那天，公司已经只剩三个人。"

这不是套模板。每段输出都在运用具体规则——「我说好节拍器」「旁观者细节工作逻辑」「以物收尾」。它不复读原文句子，它用原文的**文体骨架**写你的故事。

## 蒸馏了什么

### 7 条硬规则

| 规则 | 一句话 | 原文实证 |
|---|---|---|
| 一句一段 | 句号是唯一的奢侈品 | 413 句，中位句长 **12 字** |
| 数字精确到个位 | 报销单语感 | **161 处数字**，平均每 44 字一个 |
| "我说好"节拍器 | 回应具体有成本的要求，单独成段 | 原文恰好出现 **7 次** |
| 情绪全部留白 | 最痛处只写生理事实 | "我把手放在胸口，数了一下。心跳很稳。" |
| 旁观者细节 | 泪点交给不相干的人 | 清洁工、贴胶带的女孩、退票的观众 |
| "我没有问" | 写放弃，不写答案 | 我沉默 4 次、没有说 3 次、没有问 1 次 |
| 以物收尾 | 禁止照搬"凌晨三点的XX" | 原型尾句是强引力陷阱，必须自己找物 |

### 3 组对照公式

| 对照 | 原文示例 |
|---|---|
| 大数 vs 小数 | 五千万美元 / 八万块 / 三十卷胶带 |
| 大场面 vs 小动作 | 包下整层酒店 / 她躲在卫生间等清洁工走 |
| 无限服从 vs 一次拒绝 | 全部"我说好" → 最后一次"让我想想" |

### 核心洞察（4 轮对抗测试的产物）

- 张力来源不是财富，是**不对称关系**——一方无限给予，一方照单全收。穷人叙事同样成立（测试 R3 验证）
- 旁观者细节必须符合那个人的**工作逻辑**，否则是一眼假的"伪细节"（测试 R2 抓出）
- 两个硬门槛，缺一拒绝写：① 不对称结构 ② 失去（测试 R4 验证 skill 会拒绝喜报题材）
