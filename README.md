# sun-ge-style · 孙哥体写作 Skill

> 一颗卵子的重量，三点五微克。
> 一个写作 skill 的重量，4884 字节。
> 前者没取出来。后者，现在归你了。

## 这是什么

一个 Claude Code / Kimi Code 的写作风格 skill。
装好之后，你的 AI 就学会了 2026 年开年第一篇十万加的写法——

**用会计的笔法写爱情，用爱情的笔法写账单。**

当年新概念作文大赛教你"我手写我心"。
孙哥体教你：**我心一个字不写，你自己从账单里看。**

## 核心理念（获奖感言版）

普通作者写失恋：我很难过。
孙哥体写失恋：

```
我把手放在胸口，数了一下。
心跳很稳。
我又数了一遍，还是很稳。
```

普通作者写有钱：我很有钱。
孙哥体写有钱：

```
A330 是按两百人设计的，我们只有三十个人，太轻了，起飞的配平不对。
所以每次都要多加油，加到够重为止。
到了地方，多加的那些又不能留着，得放掉。
```

看出区别了吗。**前者是作文，后者是呈堂证供。**

## 安装

把 `SKILL.md` 丢进你的 skills 目录：

```bash
# Claude Code
cp SKILL.md ~/.claude/skills/sun-ge-style/SKILL.md

# Kimi Code / 其他 agent
cp SKILL.md ~/.agents/skills/sun-ge-style/SKILL.md
```

然后对你的 AI 说：

> 用孙哥体，写我和我前女友去淄博吃烧烤的事。

> 用孙哥体，写我们公司上一轮融黄了。

> 用孙哥体，写我抢到了五月天的票但是加班没去成。

## 三条铁律（skill 里有完整版）

1. **一句一段。** 句号是唯一的奢侈品。
2. **数字精确到个位。** 二十六个人。四十几页。快一个小时。
3. **"我说好"是节拍器。** 全文所有的"好"，都是为了最后一次"让我想想"。

## 它适合写谁

- 前任
- 前老板
- 前妻/前夫
- 暴雷的理财产品
- 倒闭的健身房
- 任何"钱花了，事没成"的人生段落
